# PivotOS Feedback Collection

This folder documents the feedback collection process for Challenge Card 02 of Grevix AfterCode 2026.

## Feedback Collection Method

PivotOS includes a built-in feedback form accessible from the Settings page. Users can submit:

- Overall satisfaction rating (1-5 stars)
- Specific feature feedback
- Bug reports
- Usability issues
- Suggestions for improvement

Feedback is stored locally in the application and can be exported for review.

## Questions Asked

The feedback form collects the following information:

1. **Overall Rating**: How satisfied are you with PivotOS? (1-5 stars)
2. **What Works Well**: What features do you find most useful?
3. **What Needs Improvement**: What could be better?
4. **Bug Reports**: Any issues or unexpected behavior?
5. **Feature Requests**: What would you like to see added?

## Evidence Checklist

When collecting feedback, record:

- [ ] Date of feedback collection
- [ ] User role (student, project manager, developer, etc.)
- [ ] Context of use (exploration, actual project planning, etc.)
- [ ] Screenshots of the feedback form submission
- [ ] Screenshots of any issues reported
- [ ] Exported feedback data file
- [ ] Summary of key insights

## Adding Evidence

To add authentic feedback evidence:

1. Take screenshots during user testing sessions
2. Export feedback data using the Settings > Export Feedback option
3. Save screenshots to the `evidence/` folder with descriptive filenames
4. Update this README with a summary of collected feedback
5. Document any changes made in response to feedback in `IMPROVEMENTS.md`
