# Feedback Evidence

This folder contains authentic evidence of user feedback collected for PivotOS.

## Adding Evidence

When adding feedback evidence, please:

1. **Screenshots**: Save screenshots with descriptive filenames, e.g.:
   - `2026-10-11-feedback-form-submission.png`
   - `2026-10-11-bug-report-issue.png`
   - `2026-10-11-user-testing-session.png`

2. **Include Context**: For each screenshot, note:
   - Date and time
   - User role/context
   - What was being tested or discussed
   - Any relevant observations

3. **Exported Data**: Save exported feedback files with timestamps:
   - `2026-10-11-feedback-export.json`

4. **Update Parent README**: After adding evidence, update `/feedback/README.md` with a summary.
